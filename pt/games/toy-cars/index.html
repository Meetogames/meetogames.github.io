Sobre o jogo

Um carrinho de brinquedo, um estilingue de borracha e um quarto de criança gigante!

Puxe o estilingue para trás e solte: o carrinho segue em frente no embalo. Vire para a esquerda e para a direita, desvie de blocos, dominós e laranjas, pegue moedas, passe pelas setas de turbo e voe das rampas.

No ar, deslize para cima para dar cambalhotas e para baixo para parar. Mais voltas e uma aterrissagem perfeita rendem mais moedas e pontos, e uma supercambalhota ainda dá um turbo extra.

Como jogar

Mouse e teclado

  • Arraste com o mouse e solte para lançar
  • Setas ou A/D para virar
  • Para cima ou W para dar cambalhota, para baixo ou S para parar
  • Espaço para o nitro, P para pausar

Celular e tablet

  • Arraste para baixo e solte para lançar
  • Deslize para a esquerda e para a direita para virar, até no ar
  • Deslize para cima para dar cambalhota e para baixo para pousar certinho
  • Toque no botão Nitro para acelerar

Pronto para jogar?

É grátis e roda direto no navegador.
